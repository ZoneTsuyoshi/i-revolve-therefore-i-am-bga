# 作者への質問と回答

ルールブック・FAQ だけでは決められない点（効果の処理順、同時処理、アナログ特有の意思表示を BGA でどう表すか、BGA 上の設定）を作者に質問し、回答を記録する。

## 運用

- 質問には必ず暫定案と根拠（ルールブックのページ・FAQ・カード番号）を添える。
- 作者が回答しなかった項目は暫定案で了承とみなし、「回答」列に「暫定案で了承（日付）」と書く。暫定案のない質問は明示の回答が必要。
- 回答がルールの裁定（カード効果の解釈など）で、プレイヤーにも有用なものはサイト側の FAQ に起票する（[faq-workflow.md](faq-workflow.md)）。「FAQ」列に起票の有無を書く。
- 回答は関連する仕様書の「未確定事項」にも反映する。
