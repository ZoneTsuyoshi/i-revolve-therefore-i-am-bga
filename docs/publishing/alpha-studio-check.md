# Studio での確認のお願い（Public Alpha 審査の前に）

BGA の Public Alpha 審査に出す前に、画面（UI）を 2 回作り直しました。パソコン上の試験用の画面では確かめられない点があるので、BGA Studio の実物で確認をお願いします。所要時間の目安は 45〜60 分です。

背景（2 段階）:

1. 姉妹プロジェクト MINIMUM JOURNEY が審査で「UI/UX が公開アルファに達していない」と指摘されたため、同じ指摘を受けないよう先回りで直しました（仕様書 [010](../specs/010-alpha-ui-review.md)）。
2. 2026-11-27 に、姉妹プロジェクト PROJECT EDGEWORTH も審査で UI を全面的に差し戻されました。審査は「部品の周りの UI が汎用的で一貫性がなく、卓上のゲームではなく独自のアプリに見える」ことを主な理由に挙げ、ガイドラインを 1 つの体系として当てはめ直すよう求めています。このゲームはまだ審査を受けていないので、同じ指摘を受けないよう、もう一度先回りで直しました（仕様書 [011](../specs/011-ui-redesign.md)。U-17〜U-20。PR #44〜#46 と、U-20 の PR）。主な変更は次のとおりです（読まなくても確認できます）。
   - 暗い卓の上に、回廊・カード・トークン・コマを直接置く見た目にした。領域の箱、丸い札、手番の太い枠と「Your turn」の札、左の浮いたジャンプボタン、想起の案内パネルをやめた。
   - 手番はプレイヤーパネルの強調とステータスバーで示す。他プレイヤーの領域へは、パネルの右端のボタンで移る。
   - ツールチップを 1 つの仕組みに作り直した（長押しの全画面の拡大表示と Select ボタンは廃止。タッチは長押しでツールチップ、タップは操作）。
   - 選べる・選択中・今は選べない・対象の見た目を、全部品で同じにした。
   - 狭い画面で読めなかった部屋の錠前に、錠前のアイコンを重ねた。英語のカード名のキャプションを既定で On にした。

## 準備

変更はすべて `main` にマージ済みで、Studio へ自動で同期されています。Studio のゲーム（`irevolvethereforeiam`）を開き直して、ブラウザを強制再読み込みしてから始めてください（古い画面が残ることがあります）。

テーブルの作り方は、BGA の公式ドキュメント（出典: <https://en.doc.boardgamearena.com/Tools_and_tips_of_BGA_Studio>）に沿って書いています。

1. Play now で、ゲームの種類を「Simple game」→「Turn-based」→「Manual」にする。
2. 作りたい人数（2・3・4 人）を、テーブルの最大人数に指定する。
3. ゲームを選んで「Create」を押し、「Express Start」を押す。
4. 別のテストプレイヤーの視点は、各プレイヤー名の横の小さな赤い矢印で、新しいタブに開ける（URL に `&testuser=<ID>` を付ける方法もある）。

テーマ（ライト・ダーク）の切り替え方と、スマホでの確認の仕方は、上の公式ドキュメントに手順の記載がありませんでした。普段 BGA を使うときの方法（アカウントの表示設定、実機のスマホで Studio のテーブルを開く）で行ってください。分からなければ、その旨を教えてください。

## 確認の進め方

次の順に確認します。各項目の「見てほしいこと」が満たされていれば OK です。NG のときは「教えてほしいこと」を添えて知らせてください。共通で知りたいのは、次の 4 つです。

- スクリーンショット（できれば画面全体。スマホは画面の撮影）
- 画面のサイズ（パソコンならブラウザのウィンドウの大きさ、スマホなら機種名）
- ブラウザの種類（Chrome、Safari など）
- どの状態のときか（何人で、どのフェイズか。例: 「4 人、自分の移動の途中」）

### A. パソコンの画面幅（ブラウザのウィンドウを広げた状態、ダークテーマ）

1. **盤面が中央にあり、回廊の環が縦に収まる**
   - 見てほしいこと: 4 人のテーブルで、画面の左右に余白があり、盤面が片側に寄っていない。回廊の環（4 × 4 の部屋）と山札の行が、スクロールなしでおおよそ見える。右の列に自分の手札の先頭が見える。
   - 教えてほしいこと: 画面サイズ、画面全体のスクリーンショット。
2. **ウィンドウを狭めたり広げたりして崩れない**
   - 見てほしいこと: ウィンドウの幅を少しずつ変えても、横スクロールが出ず、配置が行き来して点滅しない。ブラウザのズームを変えても崩れない。
   - 教えてほしいこと: 崩れたときの幅（または拡大率）と、スクリーンショット。
3. **BGA 実物の右のプレイヤーパネルが見やすい**
   - 見てほしいこと: パネルが 2 行（自己構成スコア「N / 20」と手札の枚数、鍵の本数）で、4 人でも高さが画面の 1/4 以内に収まる。
   - 教えてほしいこと: パネルの部分のスクリーンショット。
4. **ステータスバーの貼り付きとツールチップの位置**
   - 見てほしいこと: ページを下へスクロールしても、画面上部のステータスバー（「You may …」とボタン）が画面の上に貼り付いたままか。貼り付くなら、ツールチップがバーに隠れず、バーの下に出る（BGA の公式文書にはバーが貼り付くか書かれていません）。
   - 教えてほしいこと: 貼り付くかどうか。貼り付く場合、ツールチップがバーと重なる場面のスクリーンショット。
5. **パネルの移動ボタンとスクロール位置**
   - 見てほしいこと: 各プレイヤーパネルの右端の小さなボタン（下向きの矢印）を押すと、そのプレイヤーの領域までスクロールする。領域の見出し（名前の行）が、ステータスバーに隠れずに見える。ボタンが 32×32px 以上で押しやすい。
   - 教えてほしいこと: 見出しがバーに隠れるときは、どれくらい隠れるか（バーの高さ）とスクリーンショット。
6. **手番がパネルで分かる**
   - 見てほしいこと: 手番のプレイヤーが、BGA 標準のパネルの強調（光る枠など）とステータスバーの文で分かる。領域に「Your turn」の札や太い枠はもう無い。2 人以上のテーブルで、手番が替わったときに一目で追える。
   - 教えてほしいこと: 手番が分かりにくかった場面（人数、誰の番か）とスクリーンショット。

### B. ライトテーマ

1. **BGA 側の欄が暗い背景の上で読める**
   - 見てほしいこと: ゲームの背景は、ライトテーマでも暗いセピアのまま。ログ、プレイヤーパネル、ゲームの下の欄の文字が読める。盤面の文字・カードの枠は暗い背景の上で読める。
   - 教えてほしいこと: 読みにくい場所のスクリーンショットと、何が読みにくいか（文字の色、背景など）。
2. **ツールチップが読める**
   - 見てほしいこと: カードやトークンなどにマウスを乗せたときのツールチップ（英語の効果文と拡大画像）が、ライト・ダークのどちらでも読める。ツールチップは盤面の暗さに関わらず、BGA のテーマの色に従う。
   - 教えてほしいこと: どの部品か、スクリーンショット。
3. **ステータスバーの文のカード名と鍵のアイコン**
   - 見てほしいこと: 想起の中（「Recall (カード名): …」）、移動の計画、精神分析の支払いのとき、ステータスバーの文の中のカード名（下線つき）と鍵のアイコンが、記号の列（`<span …>` や `{wisdom}` のようなもの）でなく、絵や整った文字として出る。
   - 教えてほしいこと: 生の記号（`<` や `{` を含む文字）がそのまま出たときの場面とスクリーンショット。
4. **自己構成の支払いのカード名**
   - 見てほしいこと: 自己構成の支払いのステータスバーに、自己構成するカードの英語名が出る。以前は「M000」のような番号になっていた不具合を直したので、直っているか。
   - 教えてほしいこと: 番号のままのとき、そのカードと場面。
5. **`showMessage` の見た目とログ**
   - 見てほしいこと: 選べない部品（暗くなっている部屋・カード・トークン）を押すと、理由の短い文が画面に出る。同じ文を続けて押しても、2 秒以内は繰り返さない。その文がゲームのログ（右の履歴）に載っていない。ライト・ダークのどちらでも読める。
   - 教えてほしいこと: 文が出ない、ログに載る、読みにくいとき、そのときの操作とスクリーンショット。

### C. 操作と Action Bar（画面上部のボタンの帯）

2〜4 人のどれかで、実際に数ターン遊んで確認します。

1. **ボタンの色と並び**
   - 見てほしいこと: 進む操作は青、取り消し・やめる操作は赤で右端、脇の操作は白（または白枠）、押せないボタンは灰色。並びは「青 → 白 → 赤」。1 つの場面のボタンは多くても 4〜5 個。
   - 教えてほしいこと: どの場面か（移動、想起、自己構成の支払い、精神分析など）、スクリーンショット。
2. **部品を押して操作できる**
   - 見てほしいこと: 移動・自己構成・精神分析の支払いで、自分のトークン（心光、万能移動鍵）を押すと数量が増える。精神分析の行き先は、精神トラックのカードを押しても選べる。獲得できる目標カードが光り、押すと [Claim goal] が出る。万能移動鍵は、使える方と使用済みの 2 つの絵で個数つきに並ぶ。
   - 教えてほしいこと: 押しても反応しなかった部品、またはボタンと食い違った動き。
3. **選べる・選択中・今は選べない・対象の見た目**
   - 見てほしいこと: 選べる部屋・カード・トークンは細い枠、選択中は太い枠、今は選べないものは暗い。想起中、対象の部屋のカードに破線が付く。どの部品でも同じ見た目で、bga-cards の既定のオレンジの破線が出ない。経路の順番は金の四角い札で、点滅しない。
   - 教えてほしいこと: オレンジの破線が出た場面、見た目が部品によって違う場面、スクリーンショット。
4. **想起の割り込みの破線**
   - 見てほしいこと: 想起の効果で他のプレイヤーに割り込みが入るとき、答えない側（ステータスバーに「Recall …」が出ない側）の画面にも、想起中の部屋のカードの破線が出る。
   - 教えてほしいこと: 出ない側の人数と視点、スクリーンショット。
5. **ステータスバーのボタンが残らない**
   - 見てほしいこと: 移動の計画で、パネルの移動先などのボタンが、次の状態（想起や自己構成）に進んだあとに残っていない。手札のレールのボタン（「Discard 2 for Psychic Light」）も、手番が替わったり別の状態に入ったりしたあとに残らない。
   - 教えてほしいこと: 残ったボタンの名前と、どの状態の遷移のあとか。
6. **カードが飛ぶアニメーション**
   - 見てほしいこと: 手札にカードが加わる、自己構成する、目標を獲得するなどのとき、カードが正しい場所へ飛んで、途中で位置がずれたり、一瞬消えたりしない。
   - 教えてほしいこと: どの操作のときか。可能なら画面の録画。
7. **手札を捨てて心光を得る**
   - 見てほしいこと: 手札のレール（「Hand」の線の右）に、BGA 標準のボタン（「Discard 2 for Psychic Light」）が出て、押すと手札を捨てて心光に変える操作に入れる。手札が 0 枚のときは出ない。
   - 教えてほしいこと: 出ない、または押せないときの状態。

### D. 人数ごとの見え方（Express Start の 2・3・4 人）

1. **2 人・3 人でも空きが目立たない**
   - 見てほしいこと: 人数が少なくても、盤面が中央で、プレイヤーの領域が縦に長く空いていない（序盤の他プレイヤーの領域は低い）。
   - 教えてほしいこと: 何人のとき、どの部分が空いて見えるか。
2. **他プレイヤーの視点**
   - 見てほしいこと: 赤い矢印で開いた他プレイヤーの画面でも、その人の手札が見え、自分の領域が先頭に出る。観戦者の視点（公式ドキュメントに、URL を変えて試せるとある。やり方が分からなければ省略してよい）でも崩れない。
   - 教えてほしいこと: どの視点で崩れたか。

### E. 実機のスマホ（縦持ち）

1. **360〜430px 幅の画面で縮小されずに遊べる**
   - 見てほしいこと: 横スクロールが出ない。文字が小さすぎない。環の部屋が重ならない。山札が環の中央に収まる。
   - 教えてほしいこと: 機種名、ブラウザ、スクリーンショット。
2. **自分の領域が先に出る**
   - 見てほしいこと: 環と場札の下に、自分の手札・自己構成済みのカードが出て、そのあとに精神トラックと目標カード、他プレイヤーの順になっている。
   - 教えてほしいこと: 並びが違うときのスクリーンショット。
3. **パネルの移動ボタン**
   - 見てほしいこと: 左端の浮いた丸（ジャンプリンク）は無くなり、代わりに各プレイヤーパネルの右端の小さなボタンで、その人の領域へ移れる。スマホの 2 列のパネルが、2 行に収まっている。ボタンがスクロールに追従して浮いたりしない。
   - 教えてほしいこと: パネルが 3 行以上になる、ボタンが押しにくい、浮いて見える場面のスクリーンショット。
4. **タップと長押し**
   - 見てほしいこと: ボタン、トークン、パネルの移動ボタンを指で押し間違えない。カードを普通にタップすると選択（または操作）になる。カード・トークンなどを長押し（約 0.5 秒）するとツールチップが出て、指を離しても選択されない。ツールチップの外をタップする、画面をスクロールする、と閉じる。全画面の拡大表示と「Select」ボタンはもう無い。
   - 教えてほしいこと: 長押しの感触（反応が遅い・早すぎる）、長押しのあとに選択されてしまう場面、押しにくかった部品と機種名。
5. **部屋の錠前**
   - 見てほしいこと: 狭い画面（幅 600px 未満）で、回廊の部屋の裏向きカードの下寄りに、錠前の絵（本・炎・ハート）が重なって出て、種類と個数（レベル 2 は 2 つ）が読める。広い画面（パソコン）では出ず、カードの印刷のままである。経路の番号の札・ミープルを隠さない。想起中に表向きになった部屋には出ない。
   - 教えてほしいこと: 読めない、重なって邪魔、広い画面でも出るとき、画面のサイズとスクリーンショット。
6. **英語のカード名のキャプション**
   - 見てほしいこと: 設定（プレイヤー設定「Card captions」）の既定が On で、手札・自己構成済み・場札・自我・目標のカードの下に、英語の名前が 1 行出る。次の行のカードに重ならない。環の床カード・山札・精神トラックには出ない。設定を Off にすると消える。
   - 教えてほしいこと: 重なる場面とスクリーンショット。**すでに作ったテーブルの設定が、既定の変更（Off → On）に引きずられて変わらないか**（既に設定を選んだ人の値は変わらないはずです。BGA の公式文書では確認できませんでした）。変わった場合は、その旨を教えてください。

## 確認が済んだら

すべて OK（または気になる点を知らせて直した）なら、Public Alpha の審査の申請へ進みます。
