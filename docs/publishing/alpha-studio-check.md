# Studio での確認のお願い（Public Alpha 審査の前に）

BGA の Public Alpha 審査に出す前に、画面（UI）を作り直しました。パソコン上の試験用の画面では確かめられない点があるので、BGA Studio の実物で確認をお願いします。所要時間の目安は 30〜45 分です。

背景: 姉妹プロジェクト（MINIMUM JOURNEY）が審査で「UI/UX が公開アルファに達していない」と指摘されたため、同じ指摘を受けないよう先回りで直しました。内容は仕様書 [010](../specs/010-alpha-ui-review.md) にあります（読まなくても確認できます）。

## 準備

変更はすべて `main` にマージ済みで、Studio へ自動で同期されています。Studio のゲーム（`irevolvethereforeiam`）を開き直して、ブラウザを強制再読み込みしてから始めてください（古い画面が残ることがあります）。

テーブルの作り方は、BGA の公式ドキュメント（出典: <https://en.doc.boardgamearena.com/Tools_and_tips_of_BGA_Studio>）に沿って書いています。

1. Play now で、ゲームの種類を「Simple game」→「Turn-based」→「Manual」にする。
2. 作りたい人数（2・3・4 人）を、テーブルの最大人数に指定する。
3. ゲームを選んで「Create」を押し、「Express Start」を押す。
4. 別のテストプレイヤーの視点は、各プレイヤー名の横の小さな赤い矢印で、新しいタブに開ける（URL に `&testuser=<ID>` を付ける方法もある）。

テーマ（ライト・ダーク）の切り替え方と、スマホでの確認の仕方は、上の公式ドキュメントに手順の記載がありませんでした。普段 BGA を使うときの方法（アカウントの表示設定、実機のスマホで Studio のテーブルを開く）で行ってください。分からなければ、その旨を教えてください。

## 確認の進め方

次の順に確認します。各項目の「見てほしいこと」が満たされていれば OK です。NG のときは「教えてほしいこと」を添えて知らせてください。共通で知りたいのは、次の 4 つです。

- スクリーンショット（できれば画面全体。スマホは画面の撮影）
- 画面のサイズ（パソコンならブラウザのウィンドウの大きさ、スマホなら機種名）
- ブラウザの種類（Chrome、Safari など）
- どの状態のときか（何人で、どのフェイズか。例: 「4 人、自分の移動の途中」）

### A. パソコンの画面幅（ブラウザのウィンドウを広げた状態、ダークテーマ）

1. **盤面が中央にあり、回廊の環が縦に収まる**
   - 見てほしいこと: 4 人のテーブルで、画面の左右に余白があり、盤面が片側に寄っていない。回廊の環（4 × 4 の部屋）と山札の行が、スクロールなしでおおよそ見える。右の列に自分の手札の先頭が見える。
   - 教えてほしいこと: 画面サイズ、画面全体のスクリーンショット。
2. **ウィンドウを狭めたり広げたりして崩れない**
   - 見てほしいこと: ウィンドウの幅を少しずつ変えても、横スクロールが出ず、配置が行き来して点滅しない。ブラウザのズームを変えても崩れない。
   - 教えてほしいこと: 崩れたときの幅（または拡大率）と、スクリーンショット。
3. **BGA 実物の右のプレイヤーパネルが見やすい**
   - 見てほしいこと: パネルが 2 行（自己構成スコア「N / 20」と手札の枚数、鍵の本数）で、4 人でも高さが画面の 1/4 以内に収まる。
   - 教えてほしいこと: パネルの部分のスクリーンショット。

### B. ライトテーマ

1. **BGA 側の欄が暗い背景の上で読める**
   - 見てほしいこと: ゲームの背景は、ライトテーマでも暗いセピアのまま。ログ、プレイヤーパネル、ゲームの下の欄の文字が読める。盤面の文字・カードの枠は暗い背景の上で読める。
   - 教えてほしいこと: 読みにくい場所のスクリーンショットと、何が読みにくいか（文字の色、背景など）。
2. **ツールチップと拡大表示が読める**
   - 見てほしいこと: カードにマウスを乗せたときのツールチップ（英語の効果文）と、長押しの拡大表示が、ライト・ダークのどちらでも読める。
   - 教えてほしいこと: どのカードか、スクリーンショット。

### C. 操作と Action Bar（画面上部のボタンの帯）

2〜4 人のどれかで、実際に数ターン遊んで確認します。

1. **ボタンの色と並び**
   - 見てほしいこと: 進む操作は青、取り消し・やめる操作は赤で右端、脇の操作は白（または白枠）、押せないボタンは灰色。並びは「青 → 白 → 赤」。1 つの場面のボタンは多くても 4〜5 個。
   - 教えてほしいこと: どの場面か（移動、想起、自己構成の支払い、精神分析など）、スクリーンショット。
2. **部品を押して操作できる**
   - 見てほしいこと: 移動・自己構成・精神分析の支払いで、自分のトークン（心光、万能移動鍵）を押すと数量が増え、数字のバッジを押すと減る。精神分析の行き先は、精神トラックのカードを押しても選べる。獲得できる目標カードが光り、押すと [Claim goal] が出る。
   - 教えてほしいこと: 押しても反応しなかった部品、またはボタンと食い違った動き。
3. **カードが飛ぶアニメーション**
   - 見てほしいこと: 手札にカードが加わる、自己構成する、目標を獲得するなどのとき、カードが正しい場所へ飛んで、途中で位置がずれたり、一瞬消えたりしない。
   - 教えてほしいこと: どの操作のときか。可能なら画面の録画。
4. **手札を捨てて心光を得る**
   - 見てほしいこと: 手札のタブ（「Hand」の横）に小さなボタンが出て、押すと手札を捨てて心光に変える操作に入れる。
   - 教えてほしいこと: 出ない、または押せないときの状態。

### D. 人数ごとの見え方（Express Start の 2・3・4 人）

1. **2 人・3 人でも空きが目立たない**
   - 見てほしいこと: 人数が少なくても、盤面が中央で、プレイヤーの領域が縦に長く空いていない（序盤の他プレイヤーの領域は低い）。
   - 教えてほしいこと: 何人のとき、どの部分が空いて見えるか。
2. **他プレイヤーの視点**
   - 見てほしいこと: 赤い矢印で開いた他プレイヤーの画面でも、その人の手札が見え、自分の領域が先頭に出る。観戦者の視点（公式ドキュメントに、URL を変えて試せるとある。やり方が分からなければ省略してよい）でも崩れない。
   - 教えてほしいこと: どの視点で崩れたか。

### E. 実機のスマホ（縦持ち）

1. **360〜430px 幅の画面で縮小されずに遊べる**
   - 見てほしいこと: 横スクロールが出ない。文字が小さすぎない。環の部屋が重ならない。山札が環の中央に収まる。
   - 教えてほしいこと: 機種名、ブラウザ、スクリーンショット。
2. **自分の領域が先に出る**
   - 見てほしいこと: 環と場札の下に、自分の手札・自己構成済みのカードが出て、そのあとに精神トラックと目標カード、他プレイヤーの順になっている。
   - 教えてほしいこと: 並びが違うときのスクリーンショット。
3. **ジャンプリンク（画面の左端の小さな丸）**
   - 見てほしいこと: スマホ（と、狭いウィンドウ）に丸が出て、押すと「Board」「You」「Spirit & goals」と各プレイヤーへ移れる。広いパソコンの画面では出ない。丸がカードの左端に重なって邪魔になっていない（重なるときは、その旨を教えてください）。
   - 教えてほしいこと: 丸の位置が邪魔な場面のスクリーンショット。
4. **タップのしやすさ**
   - 見てほしいこと: ボタン、トークン、手札のタブのボタン、ジャンプリンクを指で押し間違えない。長押しでカードの拡大が開き、普通のタップでは選択になる。
   - 教えてほしいこと: 押しにくかった部品と機種名。

## 確認が済んだら

すべて OK（または気になる点を知らせて直した）なら、Public Alpha の審査の申請へ進みます。
